## Общие блоки

- **Header.** Фиксированная шапка с логотипом, восемью ссылками и входом в кабинет. На узком экране меню открывается кнопкой, закрывается Escape. Пункты поступают из одного перечня страниц, который допускает добавление новых разделов. Отдельный /cabinet — [уточнить].
- **Footer.** Дубль навигации, бот, MAX, контакты, форма по якорю, VK, Telegram, раскрываемые реквизиты и открытие настроек cookie. В Tilda сохранить адреса /privacy_policy и /approval. В локальных макетах доступны полные копии юридических документов из архива.
- **Согласие.** Чекбокс по умолчанию пуст. Подставить точный текст из макета и ссылку на политику. На стенде проверить серверную фиксацию версии согласия, времени и источника для формы, регистрации и оплаты.
- **Cookie и Метрика.** Три категории из ТЗ. Прототип сохраняет выбор на устройстве. Счётчик для classes — [уточнить]. На стенде настроить запуск после согласия, отзыв, отсутствие дублирования и фактические запросы.
- **SEO.** Взять уникальные title и description из head каждой страницы, согласовать alt. Снять локальный noindex только после разрешения на публичный запуск. Старые адреса и якоря сверить с владельцем и журналом переходов, записать целевой маршрут и проверить HTTP-ответы. Для смены пути нужен 301, прежние #якоря проверяются отдельно в браузере.
- **Визуальная система.** Предложение ожидает решения Татьяны. Из карточки App Forhims взяты контейнер 1200 px, сетка 12 колонок с интервалом 24 px, одна колонка на телефоне, контраст антиквы и простого интерфейсного шрифта. Адаптация студии использует Source Serif 4 и Golos Text с кириллицей, #3769A8 для CTA, #C6CD4B для акцентов. Фотографии и логотип взяты из архива студии. Источник фотографии первого экрана — 3039_IMG_8788-min.jpg. [Спецификация OpenDesign](https://www.opendesign.cc/en/sites/app-forhims).

## Настройка на стенде

Подключение T123, формы и переходы выполняются при наличии тестового проекта. До публикации сверить CSS с адаптивами макета, назначить разрешённые домены и использовать тестовые реквизиты сервисов. Публичные коды из защищённой базы доступны отдельно.
