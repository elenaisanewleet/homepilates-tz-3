2. Какие персональные данные могут обрабатываться

2.1. При использовании Приложения Оператор может обрабатывать персональные данные, предоставляемые пользователем при регистрации, заполнении профиля и использовании функций Приложения.

В зависимости от настроек конкретного Приложения к таким данным могут относиться:

фамилия;

имя;

отчество;

дата рождения;

пол;

адрес электронной почты;

основной и дополнительный номер телефона;

номер клубной карты;

промокод, используемый при регистрации;

алиас в Telegram;

ссылка на профиль в Max;

иные сведения, которые пользователь предоставляет через функциональность Приложения.

2.2. Конкретный состав данных зависит от настроек регистрации, профиля и функциональности мобильного приложения.

3. Цели обработки персональных данных

Персональные данные пользователей могут обрабатываться в следующих целях:

регистрации и авторизации пользователя в Приложении;

создания и ведения личного кабинета;

идентификации пользователя;

предоставления услуг клуба;

записи на занятия, услуги и мероприятия;

управления абонементами и клубными услугами;

информирования пользователя о записях, услугах и изменениях;

направления уведомлений;

обработки обращений пользователя;

выполнения договорных обязательств перед пользователем.

Для каждой цели рекомендуется определить соответствующий ей перечень персональных данных.

4. Правовые основания обработки

Оператор обрабатывает персональные данные пользователей при наличии соответствующего правового основания, предусмотренного законодательством Российской Федерации.

В зависимости от целей обработки такими основаниями могут являться:

согласие субъекта персональных данных;

заключение и исполнение договора, стороной которого является субъект персональных данных;

исполнение обязанностей, возложенных на Оператора законодательством Российской Федерации;

иные основания, предусмотренные законодательством Российской Федерации.

5. Способы и порядок обработки персональных данных

5.1. Обработка персональных данных может включать:

сбор;

запись;

систематизацию;

накопление;

хранение;

уточнение (обновление, изменение);

извлечение;

использование;

передачу (предоставление, доступ);

обезличивание;

блокирование;

удаление;

уничтожение персональных данных.

5.2. Обработка персональных данных может осуществляться с использованием средств автоматизации, а в предусмотренных случаях — без использования таких средств.

5.3. Передача данных осуществляется только при наличии соответствующих оснований и в объёме, необходимом для достижения заявленных целей обработки.

6. Использование платформы Mobifitness

6.1. Для обеспечения работы мобильного приложения Оператор использует программную платформу Mobifitness, предоставляемую ООО «Мобильные Технологии».

6.2. В рамках предоставления сервиса ООО «Мобильные Технологии» может осуществлять обработку персональных данных пользователей по поручению Оператора.

6.3. Такая обработка может включать сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, передачу, обезличивание, блокирование, удаление и уничтожение персональных данных в объёме, необходимом для работы соответствующих функций сервиса.

6.4. Дополнительную информацию об обработке персональных данных ООО «Мобильные Технологии» можно найти в Политике обработки и защиты персональных данных компании:

7. Доступ к функциям мобильного устройства

Для работы отдельных функций Приложение может запрашивать разрешения мобильного устройства.

Геолокация

Приложение может использовать данные о местоположении устройства для работы функций, связанных с отображением карт, построением маршрутов и/или поиском объектов.

Push-уведомления

Приложение может использовать push-уведомления для информирования пользователя о записях, услугах, событиях и иной информации, связанной с использованием Приложения.

8. Технические данные

При использовании Приложения могут автоматически обрабатываться отдельные технические сведения, необходимые для функционирования, безопасности и технического сопровождения сервиса.

К ним могут относиться:

сведения об операционной системе;

модель и характеристики устройства;

IP-адрес;

технические идентификаторы;

сведения о работе Приложения.

Персональные данные могут передаваться третьим лицам или обрабатываться привлечёнными Оператором лицами только при наличии соответствующего правового основания и в объёме, необходимом для достижения целей обработки.

К таким лицам могут относиться:

ООО «Мобильные Технологии» — в рамках работы платформы Mobifitness.

Оператор обеспечивает соблюдение требований законодательства Российской Федерации при привлечении иных лиц к обработке персональных данных.

10. Хранение персональных данных

10.1. Персональные данные хранятся не дольше, чем этого требуют цели их обработки, если иной срок хранения не установлен законодательством Российской Федерации или договором.

10.2. Сроки хранения отдельных категорий персональных данных определяются с учётом:

целей обработки;

требований законодательства;

договорных обязательств;

срока действия соответствующего согласия;

иных применимых правовых оснований.

11. Прекращение обработки и удаление данных

Обработка персональных данных прекращается, в частности:

при достижении целей обработки;

при прекращении соответствующего правового основания;

при отзыве пользователем согласия, если обработка осуществляется на основании согласия и отсутствуют иные основания для её продолжения;

при выявлении неправомерной обработки;

в иных случаях, предусмотренных законодательством Российской Федерации.

После прекращения обработки персональные данные удаляются или уничтожаются в порядке и сроки, установленные применимым законодательством.

12. Удаление учётной записи в мобильном приложении

Пользователь может инициировать удаление своей учётной записи через функциональность мобильного приложения.

В приложениях на платформе Mobifitness соответствующая функция доступна в личном кабинете пользователя через действие «Удалить аккаунт».

Удаление учётной записи влечёт прекращение обработки и удаление связанных с ней данных в порядке, предусмотренном законодательством, условиями обработки и применимыми обязательствами Оператора.
